# LA24-R02｜Tour Archive related module

```yaml
asset_code: LA24-R02
campaign: live-album-2024
display_name: Tour Archive related module
asset_type: COMPONENT
site_role: RELATED
format: responsive
priority: P0

purpose:
  primary: LIVE ALBUM 2024から、その音源の起点となったLIVE TOUR COMPLETEへ戻す
  secondary:
    - ライブアルバムと2024ツアーの関係を明示する
    - ツアー本編の構成・ビジュアル・セットリストへの導線を作る
    - 同一ライブ素材の二重登録を避け、既存canonical archiveを再利用する

dependency:
  required:
    - LIVE TOUR COMPLETE

data_policy:
  create_duplicate_live_archive: false
  create_duplicate_assets: false
  create_duplicate_recordings: false
  target_source: existing_canonical_live_tour_complete
  artwork_source: existing_selected_live_tour_asset
```

LA24-R02は、LIVE ALBUM 2024内に新しい「ツアー紹介」を作るコンポーネントではない。役割は一貫して**LIVE TOUR COMPLETEへ戻すこと**であり、配置は`Related`、依存先は`LIVE TOUR COMPLETE`、形式はresponsive componentとして定義されている。既存canonical asset / recordingを参照し、内容を複製しない。

## Module Concept

ライブアルバムで「音として再構成された2024年ツアー」を聴いたあと、その原点となる**ツアーそのものの記録**へ戻れる導線とする。

LIVE ALBUM側で語るのは、

> この音は、どのライブ世界から生まれたのか。

まで。

ツアーの詳細、各章の説明、セットリスト、ツアービジュアル、関連記事などは、すべてLIVE TOUR COMPLETE側へ委ねる。

2024年ツアーは`SOLAR / LUNAR / EQUINOX / SHADOW`の四章で構成され、光、夜、五人の均衡、影という異なる温度を一公演の中で辿る作品として設定されている。

## Display Copy

### Eyebrow

**FROM THE LIVE ARCHIVE**

### Title

**IGNITE LIVE TOUR 2024**
**SOLAR / LUNAR / EQUINOX / SHADOW**

### Description

ライブアルバムの原点となった2024年ツアーへ。

SOLARの熱、LUNARの静けさ、EQUINOXの均衡、SHADOWの影。
音源として再構成される前のステージ、その流れと記録をLIVE ARCHIVEで辿る。

### CTA

**VIEW LIVE TOUR COMPLETE**

ここでは開催日・会場名・録音地などを補足しない。LA24-R02の目的はArchiveへの導線であり、ツアー固有情報はリンク先canonical contentを正本とする。

## Visual Treatment

LA24-R02自体は新規Artwork assetではないため、LIVE ALBUM 2024のVisual Directionを**UIのフレーム・背景・transition**へ適用し、ツアー画像そのものは既存LIVE TOUR COMPLETE素材を使う。

```yaml
visual:
  module_background:
    base: near_black
    transition:
      left: platinum_gold_orange
      center: deep_blue_indigo
      right: red_purple_near_black

  image:
    source: canonical_live_tour_selected_asset
    generate_new: false
    crop: responsive
    preserve_original_context: true

  effects:
    allowed:
      - restrained light afterimage
      - subtle glass/reflection layer
      - low-opacity blue/red edge glow
    prohibited:
      - generated typography
      - fake tour logo
      - fake venue/date information
      - new concert scene
```

つまり、**アルバム側の色調でツアーArchiveを包むが、ツアー画像をアルバム仕様へ作り替えない**。

## Content Contract

```yaml
related_target:
  type: LIVE_ARCHIVE
  relation: SOURCE_LIVE_TOUR
  required_status: published
  target: LIVE_TOUR_COMPLETE

display_fields:
  eyebrow: static
  title: target.title
  subtitle: target.subtitle
  description: component_editorial_copy
  image: target.selected_related_or_hero_asset
  href: target.canonical_route

optional_fields:
  archive_label: true

never_copy:
  - full_setlist
  - tour_schedule
  - venue_list
  - recording_metadata
  - tour_gallery
  - tour_article_body
```

ツアーはLIVE ALBUMの「関連作品」ではなく、**source context**として扱う。

この区別は重要で、Discographyの関連リリースカードのような「別作品をおすすめする」UIにはしない。

## Interaction

CTA選択時はLIVE TOUR COMPLETEのcanonical routeへ遷移する。

```yaml
interaction:
  primary_action:
    label: VIEW LIVE TOUR COMPLETE
    action: navigate
    target: canonical_live_tour_complete_route

  open_mode: same_window

  tracking:
    event: related_archive_open
    source: live-album-2024
    target: live-tour-complete
```

新規Detail modalや簡易Tour summaryをLA24-R02内で開かない。

「まず軽く見せるため」にArchive情報を複製すると、後からLIVE TOUR COMPLETEと内容差が発生するため避ける。

---

## Canonical Relationship

```text
LIVE TOUR COMPLETE
        │
        │ source context
        ▼
LIVE ALBUM 2024
        │
        │ LA24-R02
        └──────────────────► LIVE TOUR COMPLETE
```

LIVE ALBUM 2024は、2024ツアーを別履歴としてコピーするのではなく、そのツアーから生まれた作品として接続する。

2024年ツアー自体は、SOLARで始まり、LUNAR、EQUINOX、SHADOWを経て五人が再び同じ場所に立つ構成を核としているため、Related moduleでもこの四章名を省略せず表示する。

## Responsive Rules

**Desktop ≥ 1024px**
横長2カラム。画像45〜50%、本文50〜55%。

**Tablet 768–1023px**
画像上、本文下。または狭い2カラム。

**Mobile < 768px**
完全1カラム。タイトルの`SOLAR / LUNAR / EQUINOX / SHADOW`は折り返し可。

画像比率は固定しすぎず、canonical assetの主要人物や構図を壊さない`object-position`を優先する。

## Acceptance Criteria

1. LIVE ALBUM 2024の`Related`領域に表示される。
2. CTAはLIVE TOUR COMPLETEへ接続する。
3. 2024ツアーのcanonical routeを利用する。
4. ツアー用の新規Archive recordを作らない。
5. 新規Recordingを作らない。
6. 新規Artworkを必須としない。
7. 既存SELECTED Tour visualを再利用する。
8. `SOLAR / LUNAR / EQUINOX / SHADOW`のツアー名を維持する。
9. ツアー日程・会場・セットリストをmodule内へ複製しない。
10. LIVE TOUR COMPLETEが非公開・不存在の場合はmodule自体を非表示にする。
11. Desktop / Tablet / Mobileで成立する。
12. LIVE ALBUMを孤立したDiscography作品にせず、**「ツアー → ライブアルバム → ツアーArchive」**という往復可能な情報構造を成立させる。
