# LA24-R01｜24 Track Player

## Component Definition

```yaml
asset_code: LA24-R01
campaign: live-album-2024
display_name: 24 Track Player
asset_type: COMPONENT
site_role: DISCOGRAPHY
format: responsive
priority: P0

purpose:
  primary: LIVE ALBUM 2024の全24曲をDisc単位で再生・閲覧できるプレイヤー
  secondary:
    - 各曲のTrack Noteへの展開
    - 既存Recording / Track Artwork / Song Detailへの接続
    - ツアーで変化したアレンジをアルバム単位で体験させる

dependency:
  required:
    - LIVE TOUR COMPLETE
    - LA24-D01
  related:
    - LA24-D02
    - LA24-P01

data_policy:
  canonical_track_count: 24
  disc_count: 2
  disc_1_tracks: 12
  disc_2_tracks: 12
  create_duplicate_recordings: false
  create_duplicate_track_assets: false
  recording_source: existing_canonical_recording
  artwork_source: existing_selected_track_artwork
  song_detail_source: existing_canonical_song_detail
```

本コンポーネントは旧「23曲Player」仕様を使用せず、**M11.0Aで確定した24曲・12曲＋12曲構成**を正本とする。Electric BlueはDisc 2のTrack 17に入り、それ以降はGlass Ceiling＝18、Shadowplay＝19、SHADOW＝20、5 VOICES＝21、Run With Us＝22、One More Flame＝23、We Burn＝24へ移行する。Recording identityは新規複製しない。
Asset Definition上もLA24-R01はDISCOGRAPHY配置のresponsive componentであり、24-track correction適用済みとして定義されている。

## Track Row Definition

各Track Rowは最低限、以下だけを保持する。

```yaml
track:
  release_track_ref: canonical_release_track_id
  recording_ref: canonical_recording_id
  disc: 1 | 2
  disc_track_number: integer
  album_track_number: integer
  title: canonical_title

display:
  artwork_ref: selected_square_track_asset
  duration: recording_metadata
  playable: derived_from_recording_state

links:
  song_detail_ref: canonical_song_detail
  track_note_ref: live_album_track_note
```

**title、duration、audio URL、artwork URLをLA24-R01独自データとして複製しない。**

Playerは表示層であり、Release / Song / Recording / ReleaseTrackの正本Relationを参照して構築する。Recording identityを重複させない方針は24-track migrationでも明示されている。

## Now Playing

Now Playing領域に表示するものは以下。

* Track Artwork
* Album Track Number
* Track Title
* Disc
* Playback progress
* Elapsed / Duration
* Previous
* Play / Pause
* Next
* Track Note toggle / expansion
* Song Detail link

**メンバー名・作詞作曲クレジット・公演日・会場名は、canonical metadataに存在する場合だけ表示する。**

LIVE ALBUM用に推測して補完しない。

## Disc Visual State

### DISC 1

色遷移：

**Platinum / Gold / Orange → Deep Blue / Indigo**

前半のSOLAR Blockでは明るい白金・金・橙。Track 9 Moonlit以降は背景とPlayer accentを徐々にDeep Blue / Indigoへ移行する。

### DISC 2

色遷移：

**Black / White / Platinum → Electric Blue → Red / Purple / Near Black**

Track 13 Silent Signalでは白・黒・青を基調とし、Track 17 Electric BlueでElectric Blueを最も強く出す。Glass Ceiling以降は赤と紫を増やし、SHADOW付近でNear Blackまで落とす。5 VOICESで一度彩度を抑え、Encoreでわずかに開放する。

**Trackごとに別テーマへ全面切替するのではなく、アルバム全体を一続きの色遷移として扱う。**

## Track Note

Playerの重要機能は、単なる24曲再生ではなく**Track Noteを同じ画面で展開できること**とする。

### Default

Track選択時には2〜4行程度のShort Noteを表示。

内容は、

* Live arrangement
* Instrumentation
* Performance focus
* ツアーで変化したポイント

のいずれかを中心にする。

歌詞解説そのものや、スタジオ版の紹介文の再掲にはしない。

### Expanded

`READ TRACK NOTE`で詳細を展開する。

```text
TRACK NOTE
──────────

Heatwave

Horn SectionとEMBERのレスポンスを中心に
再構成されたSOLAR blockのライブアレンジ。
Trumpet / Trombone / Tenor Saxが、
五人と客席の間を行き来するように配置される。

[VIEW SONG DETAIL]
```

Track Note本文はTrack-by-Track Packを参照し、Player component自身に24本をハードコードしない。

## Playback Behaviour

* 初期状態では自動再生しない。
* Track row選択でNow Playingを更新。
* Play中に別Trackを選択した場合、そのTrackへ切替。
* Disc末尾から次Discへの自動遷移は許可。
* Track 12 Afterglow → Track 13 Silent SignalはDisc boundaryをUI上で明示する。
* Track 24 We Burn終了後はTrack 1へ自動ループしない。
* Shuffleは設けない。
* Repeatは初期仕様では設けない。

この作品は24曲の並びそのものにSOLAR / LUNAR / EQUINOX / SHADOWの流れがあるため、通常の音楽ライブラリPlayerよりも**アルバム順再生を優先するUI**とする。2024年ツアー自体も四章構成で設計されている。

## Preview / Release State

Phase 1で先行公開されたRecordingが存在する場合も、正式リリース時に別Recordingを作らない。

特に、

* Heatwave
* Moonlit
* Silent Signal

については、PreviewからAlbum Releaseへ同じstable Recording identityを引き継ぐ設計とする。Action Planでも、Phase 1 previewのRecording IDを固定し、Phase 2で再利用して重複登録を避けることが要求されている。

```yaml
recording_state:
  preview:
    playable: true
    relation: PREVIEW

  released:
    playable: true
    relation: canonical_live_album_recording
```

状態変更はRecordの差し替えではなく、既存Recordingの公開状態・Relation更新で処理する。

## Responsive Rules

**Desktop ≥ 1024px**

2カラム構成。左または上部にNow Playing、右または下部にTrack List。Disc 1 / Disc 2を同時表示可能。

**Tablet 768–1023px**

Now Playingを上段、Disc switcherとTrack Listを下段。

**Mobile < 768px**

Disc tab方式。1 Disc＝12 row。Track Noteはaccordion展開。

音源再生中もTrack Listを閲覧できるようにし、Player全体をmodalにはしない。

## Integration Contract

```yaml
component_id: live-album-2024-track-player

reads:
  - release: live-album-2024
  - release_tracks
  - recordings
  - selected_track_artworks
  - track_notes
  - song_detail_routes

must_not_create:
  - Song
  - Recording
  - ReleaseTrack
  - Artwork
  - SongDetail

fallbacks:
  missing_audio:
    state: unavailable
    hide_play_control: true

  missing_artwork:
    use: live_album_release_artwork

  missing_track_note:
    hide_track_note: true

  missing_song_detail:
    hide_song_detail_link: true
```

既存canonical asset / recordingを参照し、新たな重複AssetやRecordingを作らないことがLA24-R01の制作要件そのものである。

## Acceptance Criteria

1. **24曲が表示される。23曲仕様を残さない。**
2. Disc 1＝12曲、Disc 2＝12曲。
3. Electric Blue＝Album Track 17。
4. We Burn＝Album Track 24。
5. Preview Recordingを正式版として再利用できる。
6. Audio / RecordingをComponent内で複製しない。
7. Square Track Artworkは既存SELECTED Assetを参照する。
8. 各曲からTrack Noteを開ける。
9. 利用可能な曲ではSong Detailへ遷移できる。
10. SOLAR → LUNAR → EQUINOX → SHADOWの音楽的・視覚的流れを維持する。
11. Desktop / Tablet / MobileでPlayerとTrack Listを同時に利用できる。
12. LIVE TOUR COMPLETEとのRelationを維持し、ライブアルバムをツアーから切り離した独立履歴として複製しない。
