# TOUR LOG — TOKYO OPENING

## 最初の一歩は、まだ揃っていなかった

暗転の中、五人は別々の場所にいた。

LIVE TOUR 2024 **“SOLAR / LUNAR / EQUINOX / SHADOW”**。四章を巡るツアーの最初の景色は、五人が横一列に並ぶ姿ではない。

**IGNITE // OPENING SIGNAL**が鳴り、それぞれ別の通路からステージへ向かう。

KAIは客席を見渡す。
SHOは立ち位置を確かめる。
LEOは張りつめた空気の向こうにいるEMBERへ目を向ける。
RENは最初の音を待つ。
YUTOは一度だけ深く息を吸う。

まだ、五人は離れている。

そして「IGNITION」。

最初のビートとともに距離が縮まり、中央でこの日最初のフォーメーションが完成する。

何度も歌ってきた始まりの曲。それでも、このツアーではもう一度「ここから始める」ための曲になった。

これからSOLARへ進み、LUNARを通り、EQUINOXで再び集まり、SHADOWまで辿り着く。

その長い物語の最初にあったのは、大きな答えではない。

暗闇の中から五人が歩き出し、同じ場所に立つ。

ただ、その一瞬だった。
