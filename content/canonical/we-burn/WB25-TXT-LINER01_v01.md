# We Burn — Single Release Notes

FUTURE / NOW / ORIGIN.

五人が同じ道を歩かなくても、同じ熱を持ち続けられる。IGNITEの7th Single『We Burn』は、未来・現在・原点という三つの視点から、次の活動期へ向かう五人を描いた作品。

FUTURE —「We Burn」 異なる未来へ踏み出す五人の意思を、力強い歌声と開放感のあるサウンドで表現した宣言曲。

NOW —「NO PLAN」 リズムのズレや反復、即興的な展開を取り入れたExperimental Dance-Funk。答えを出す前に動き始める、現在の五人の自由な衝動を鳴らす。

ORIGIN —「Back to the Spark - Live Version -」 初期の楽曲を現在の五人がライブで再演。歌声と客席の熱が重なり、原点の火を未来へとつないでいく。

FIVE DIRECTIONS. ONE FIRE.

異なる三曲を通じて、変わり続ける五人と、変わらず共有する熱を記録したシングル。
